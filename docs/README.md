# про.стим

«про.стим» объединяет удалённую работу с пользовательскими проектами, инструменты ИИ, визуальную ленту приложений и паблишинг игр через оператора в Молдове. Пользователь работает со своими файлами и Git из браузера компьютера или телефона. Посетители смотрят демонстрации проектов, поддерживают авторов и участвуют в обсуждениях.

## Документация проекта

- [Описание продукта](product.md) определяет аудиторию, направления сервиса, роли и коммерческую модель.
- [Паблишинг и расчёты](publishing.md) описывает заявку, договор, выпуск игры, отчётность и выплаты разработчику.
- [ИИ сервис](ai-service.md) описывает доступ к моделям, условия провайдеров, учёт расходов и выполнение задач.
- [Удалённая работа](remote-work.md) описывает связь устройств, локальные проекты, Git, MCP и управление рабочим столом.
- [Облачные проекты](cloud-projects.md) описывают GitHub, Google Drive, Яндекс Диск и доступ к папке через браузер.
- [Интерфейс и первый релиз](feed-and-mvp.md) определяет ленту, комментарии, обсуждения, архитектуру и критерии готовности.

## Текущий этап

Создана [основа веб-интерфейса](../site/README.md) с разделами «Лента», «Steam» и «ИИ-мир». Документация описывает целевой продукт и дальнейшую реализацию. Комиссия издателя, тарифы ИИ, юридическая форма оператора и платёжные партнёры выбираются отдельно.

Для дальнейшей разработки используется русскоязычный адаптивный веб-интерфейс с возможностью установки как PWA. Главные разделы доступны из одного приложения и связаны общими аккаунтом и проектами.

ИИ и удалённая работа проектируются для пользователей из Молдовы и других поддерживаемых стран. Основной режим сохраняет исходники и историю работы в среде пользователя. Публичные публикации, обсуждения и данные кабинета размещаются на платформе.
